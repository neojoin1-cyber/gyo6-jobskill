# 학교 사용 준비 전수 점검 (2026-08-29)

## 판정

- 학생 자율학습: 회원가입 안내부터 단원 학습, 형성평가, 오답, 실전 작성까지 직선 흐름 확인
- 교사 지도: 학급 선택부터 수업, 진단, 약점, 진도, 성취, 인성, 취업 준비, 첨삭, 면접 코칭, 메시지, 미션까지 연결 확인
- 공용 PC: 사용자별 기기 저장, 동기화, 과목별 초기화, 저장 후 종료, 계정 데이터 삭제 확인
- 체험판: 실제 학교 데이터와 분리하고 체험 저장은 서버에 남기지 않음

## 학생 전체 흐름

1. 학교·학과·학년·학급 확인 후 가입
2. 오늘 학습 또는 학습관 선택
3. 단원 목표와 상황 확인
4. 먼저 판단하고 답 선택
5. 정답 근거와 오답 이유 확인
6. 상황별 심화와 실제 사례 확인
7. 3문항 형성평가(회상 2문항, 변형 1문항)
8. 오답노트와 다음 단원 연결
9. 자기소개서·면접은 작성 근거, 지원처, 직무, 경험, 완성본, 교사 첨삭 순서로 진행

## 교사 전체 흐름

1. 담당 학급 선택
2. 학급별 최근 수업 위치와 다음 차시 확인
3. 학생과 같은 학습 화면으로 수업 시작
4. 차시별 교사 지원 자료와 발문 사용
5. 진단·약점·진도·성취·인성·취업 준비 현황 확인
6. 학생별 메시지, 작성본 첨삭, 9단계 면접 코칭
7. 과목·영역·문항 수·시간·마감일을 정해 미션 초안 생성
8. 채점함과 성장 순위로 후속 지도

## 이번 적대적 검증에서 수정한 결함

- 숫자가 포함된 공지문을 수리 문제로 오인하던 학습 전략 분류 수정
- 영어 문항에 수리 풀이 순서가 붙던 분류 수정 및 해석 지원 연결 강화
- 해설의 정답 번호와 실제 정답이 다른 12건 수정, 자동 차단 규칙 추가
- 단원 개요에 암산·중간값 같은 무관한 교사 조언이 나오던 문제 수정
- 가입할 학급이 없거나 조회에 실패했을 때 원인을 알 수 없던 화면 수정
- 교사 수업 화면의 상단 뒤로가기를 교사 캠퍼스 복귀로 명확히 분리
- 선택 학급이 메시지·첨삭 화면에서 사라지던 체험 경로 수정
- 체험판의 채점함·성장 순위·미션 만들기가 빈 서버 조회로 빠지던 문제 수정
- 취업 준비 포트폴리오와 지도 통계가 학급을 바꿔도 같은 학생을 보이던 문제 수정
- 교육부 직업공통능력과 NCS 직업공통능력의 평가 주체 설명 수정

## 자동 검증 범위

- 6개 학습관, 172개 단원, 981개 핵심 학습 카드
- 학생 사례·해설 981개, 교사 지원 자료 2,214페이지
- 전체 문항 파일 40개, 5,765문항 품질 게이트
- 172개 단원별 3문항 형성평가
- 자기소개서 30유형, 면접 기본 168문항, 심화 795문항
- 지원처 120곳, 맞춤 조합 1,200건
- 학과 1,271개, 자격 73개, 학과·활동·자격 맞춤 예시 연결
- PC·Android 뒤로가기, 공용 PC 격리, 동기화, 종료 복구, 계정 삭제, 보안
