# 작업지시서 — 홈페이지 「체험해 보기」 안내 페이지

**의뢰** 설탕과소금 · **수행** 홈페이지 관리자 · **작성일** 2026-08-24
**대상 사이트** https://gyo6.kr

---

## 0. 목적

학교 관계자(교사·교감·취업부장)가 **가입 없이** 앱을 직접 만져 보게 한다.
계정 3개를 공개하고, 무엇을 눌러 보면 되는지까지 안내한다.

읽는 사람은 **앱을 처음 보는 교사**다. 용어를 설명 없이 쓰지 않는다.

---

## 1. ⚠ 선결 조건 — 이것부터 확인할 것

**웹 체험본이 2026-06-25 자로 멈춰 있다.**

```
https://neojoin1-cyber.github.io/gyo6-jobskill/
Last-Modified: Thu, 25 Jun 2026 05:51:46 GMT
```

그 뒤 두 달간 들어간 것(교사 가로 수업 모드, 문항 4지선다 정비, 수업 참여 확인
등)이 **반영돼 있지 않다.** 이 상태로 안내하면 체험자가 보는 화면과 홍보 문구가
어긋난다.

> **개발 담당이 최신본을 배포한 뒤** 이 페이지를 공개할 것.
> 배포 전이라면 페이지를 만들되 **비공개로 두고 링크를 걸지 않는다.**

## 2. 체험 계정

| 역할 | 아이디 | 비밀번호 |
|---|---|---|
| 학생 | `demo.student@sugarsalt.kr` | `sugarsalt2026` |
| 교사 | `demo.teacher@sugarsalt.kr` | `sugarsalt2026` |
| 학교관리자 | `demo.admin@sugarsalt.kr` | `sugarsalt2026` |

**확인된 사항** (2026-08-24 실측)

- 세 계정 모두 **모든 교재·모든 단원**이 열린다.
- **동시 접속이 된다.** 같은 계정으로 여러 명이 같이 써도 서로 로그아웃되지 않는다.
- 실제 학교 데이터와 **격리**돼 있다. 「설탕과소금 체험학교 / 체험 1반」 소속이며,
  다른 학교 학생 명단·제출물·오답·알림은 조회되지 않는다(전부 0건 확인).
- 전국 랭킹에 뜨지 않는다.

## 3. 접속 경로 — 두 가지를 모두 안내

### ① 웹 (설치 없이)

```
https://neojoin1-cyber.github.io/gyo6-jobskill/
```

- PC·태블릿·휴대폰 브라우저에서 바로 열린다.
- **교사용 가로 수업 화면을 보려면 PC 가 낫다.**

### ② 안드로이드 앱

- 앱 이름 「직업공통능력학습」 · 패키지 `com.gyo6.jobskill`
- [검증필요] Play 스토어 링크 — 내부 테스트 단계이므로 **테스터 등록이 된 사람만**
  설치된다. 공개 링크가 준비되기 전에는 「준비 중」으로 표기하고 링크를 걸지 않는다.

## 4. 역할별 체험 시나리오 — 페이지에 그대로 싣는다

각 시나리오는 **3~5분 안에 끝나는 분량**으로 쓴다. 클릭 경로를 빠뜨리지 않는다.

### 학생 (`demo.student@`)

1. 로그인 → 홈에서 **오늘의 도전** 카드 확인
2. 하단 **학습** → 교재 하나 선택 → 영역 → 단원 → 문항 풀기
3. 문항을 틀린 뒤 **오답노트** 탭에서 다시 확인
4. **랭킹** 탭에서 학급 순위 확인

> 안내 문구에 넣을 것 — 「듣기 문항은 소리가 납니다. 이어폰을 준비하세요.」

### 교사 (`demo.teacher@`)

1. 로그인 → 오른쪽 위 **▭ 가로** 를 눌러 수업용 화면으로 전환
2. **수업 시작** → 「문항으로 수업」 → 영역·단원 선택
3. 화면 좌우를 눌러 문항을 넘기고, **Space** 로 정답 공개
4. 도구줄에서
   - **⏱ 생각** 60초 타이머
   - **🎲 지목** 학생 무작위 지목
   - **📄 지문 접기** 글자 키우기
5. **수업 덱** 으로 들어가 차시 자료를 띄워 보기

> 안내 문구에 넣을 것 — 「가로 모드는 프로젝터·전자칠판에 맞춘 배치입니다.
> 세로로 되돌리려면 ▯ 세로 를 누르세요.」

### 학교관리자 (`demo.admin@`)

1. 로그인 → 학급·학생 현황 확인
2. 학급 만들기 / 교재 배정 화면 둘러보기

> [검증필요] 학교관리자 화면의 정확한 메뉴 구성은 개발 담당에게 확인해 캡처를 받을 것.

## 5. 페이지 구성 요구사항

### 5-1. 섹션 순서

| # | 섹션 | 내용 |
|---|---|---|
| 1 | 머리말 | 「가입 없이 바로 체험해 보세요」 + 체험 버튼 |
| 2 | 계정 표 | 3개 계정, **복사 버튼** 포함 |
| 3 | 역할별 시나리오 | 탭 또는 아코디언으로 셋 구분 |
| 4 | 주의사항 | 아래 5-3 문구 그대로 |
| 5 | 문의 | 담당자 연락처 |

### 5-2. 기능 요구

- **복사 버튼** — 아이디·비밀번호를 한 번에 복사. 교사가 휴대폰으로 보며 PC 에
  입력하는 상황이 많다. 오타를 줄이는 것이 목적이다.
- **반응형** — 휴대폰에서 표가 옆으로 넘치지 않을 것.
- 체험 버튼은 **새 창**으로 연다(`target="_blank" rel="noopener"`).
  안내를 읽으면서 앱을 만질 수 있어야 한다.

### 5-3. 주의사항 문구 — 아래를 그대로 쓸 것

> **여러 분이 함께 쓰는 체험 계정입니다**
>
> - 같은 계정에 여러 명이 동시에 접속할 수 있습니다. 서로 로그아웃되지 않습니다.
> - 다만 **학습 기록(점수·진도·오답)은 함께 쌓입니다.** 다른 분이 푼 문항이
>   내 기록에 보일 수 있습니다.
> - 체험 계정의 기록은 **주기적으로 초기화**됩니다.
> - 실제 학교 데이터와는 분리되어 있어, 체험 중 무엇을 눌러도 다른 학교에는
>   영향이 없습니다.
> - 개인정보를 입력하지 마세요. 메시지·이름 입력란에 실명이나 연락처를 적지 마세요.

## 6. 하지 말 것

1. **비밀번호를 이미지로만 넣지 말 것.** 복사가 안 되면 오타가 난다.
2. **「무료 체험」「무료 가입」 같은 표현 금지.** 가격 정책이 정해지지 않았다.
3. **학교 실명·학생 사진을 예시로 쓰지 말 것.**
4. **앱 스토어 링크를 임의로 걸지 말 것.** 내부 테스트 단계다(§3-②).
5. 체험 계정으로 **로그인한 화면을 캡처해 올릴 때** 다른 계정 정보가 찍히지
   않았는지 확인할 것.

## 7. 완료 기준

- [ ] 개발 담당이 웹 체험본을 최신으로 배포했음을 확인(§1)

- [ ] 복사 버튼이 아이디·비밀번호를 정확히 복사
- [ ] 휴대폰(가로·세로)과 PC 에서 레이아웃 깨짐 없음
- [ ] 주의사항 문구(§5-3)가 빠짐없이 들어감
- [ ] 스토어 링크가 걸려 있지 않음(준비 중 표기)
