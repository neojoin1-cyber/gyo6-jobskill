# 문제은행 독립 생성·300% 확대 검증보고서

- 기준일: 2026-09-04
- 대상: JOB고 자율학습, 진단평가, 모의고사 문항 엔진
- 결론: 기존 문항 내용을 입력으로 사용하지 않는 독립 생성 엔진을 구현했고, 7개 평가 풀을 확대 전의 정확히 300%로 늘렸다.

## 1. 사용자 정정 요청의 반영

신규 문항은 기존 문제은행의 발문, 지문, 보기, 정답, 해설을 가져와 변형한 문항이 아니다.

생성기가 읽는 입력은 다음으로 제한했다.

- 공식 평가틀의 영역명·하위능력·수행 수준
- 기출·형성평가·예시문항에서 정리한 구조 틀: 지문 유형, 인지 수준, 4지선다, 듣기·표·도표 사용 비율, 제한시간과 문항 수
- 자율학습 교육과정의 단원명과 지원처 메타데이터
- 확대 전 영역별 문항 수

생성기 소스에서 다음 기존 문항 파일의 import를 금지했고, 자동 감사가 이를 매 빌드마다 확인한다.

`questions.json`, `ncs-questions.json`, `interview-quiz.json`, `personality-test-bank.json`, `mock-interview-pool.json`, `general-knowledge-questions.json`

## 2. 평가별 재현 수준 판정

### 교육부 직업공통능력 인증진단

출시 규격을 정확히 재현한다. 2026학년도 공식 안내의 의사소통 국어 50문항·50분, 의사소통 영어 50문항·50분, 수리활용 50문항·50분, 문제해결 32문항·50분, 직무적응 160문항·40분을 그대로 적용했다. 앱의 1회 인증진단은 총 342문항·240분이다.

직무 맥락과 현실 제약 안에서 알고 있는 것을 활용하는 구조, 의사소통 듣기, 수리활용 표·도표, 문제해결의 문제인식·대안탐색·실행·성찰을 문항 설계틀에 반영했다.

### NCS 직업기초능력 26v1

2025년 12월 개편 직업공통능력 표준의 7개 영역·21개 하위능력을 사용한다. 문항마다 `ncsAbility`, `ncsElement`, `standardId` 연결을 강제했다. NCS 채용필기는 기관·직무별로 영역, 문항 수, 제한시간이 다르므로 하나의 시험과 동일하다고 표시하지 않는다. 앱은 공개 표준의 능력단위를 범위별 30문항 모의고사와 40문항 진단으로 연습하는 엔진이다.

### 채용필기 심화·확장

공공기관형·금융권형·대기업형의 영역 조합을 따로 구성한다. 연산, 자료해석, 자원관리, 조직이해, 금융·경제·경영 기초 등을 직무 사례로 구성했다. 기업별 실제 시험은 수시로 바뀌므로 응시 시점의 공식 공고가 최종 기준이다.

### 고졸 공정채용 면접·자기소개서

정답을 암기하는 시험으로 위장하지 않고, 블라인드·능력중심·구조화 면접의 행동 판단과 답변 개선 연습으로 구성했다. 자기소개서는 문항 의도, 지원처·직무 조사, 경험 근거, 답변 구조, 사실·블라인드, 최종 검수의 6영역을 실제 고쳐쓰기 선택지로 평가한다.

### 직무적응·인성검사

이 두 평가는 지식형 정답을 고르는 시험이 아니다. 정·역문항 쌍, 응답 일관성, 인상관리, 주의확인 문항을 분리했다. 앱 결과는 연습용이며 공식 선발검사의 합격·불합격이나 임상적 진단으로 사용하지 않는다.

## 4. 정답·해설·중복 검증

- 신규 6,694문항의 ID, 스키마, 평가 전용 표시 전수 검사
- 객관식 모든 문항의 4개 고유 보기, A-D 정답 코드, 정답 문구 일치 검사
- 수치·표·도표 446문항을 제시 자료에서 독립 재계산해 정답과 해설에 재대조
- 기존 평가 2,234문항과 신규 문항의 지문·발문·보기 완전 중복 0건
- 신규 문항 상호 완전 중복 0건
- 정답 위치 A-D 분포 편차 3% 이내
- ‘정답만 가장 긴 보기’ 비율: 직업공통 9.1%, NCS 9.4%, 채용필기 0%, 면접 18.2%, 자기소개서 0%
- 자기소개서 36문항의 실전 첨삭형 보기 길이·정답 위치·단서 비율 검사
- 직무적응·인성검사의 정·역문항 쌍 양방향 연결, 응답 문장 중복 0건

새 풀의 회차 도달성도 확인했다. 자기소개서 36문항과 직무적응 480문항은 3회 이내에 전체가 출제되며, 인성검사 3,090문항은 전체 제공 회차를 통해 모두 도달한다.

## 5. 함께 수정한 엔진 결함

- 런타임 중복 제거기가 서로 다른 사례 지문을 중복으로 오판하던 문제를 수정했다.
- 모의고사 조립 직전에 지문·발문·보기 내용 키로 중복을 제거하도록 공통 조립기를 보강했다.
- 자기소개서 평가가 매번 첫 12문항만 보여 주던 구조를 3회 순환 출제로 수정했다.
- 직무적응과 인성검사는 1회 응시 길이를 무작정 늘리지 않고, 회차를 바꾸어 확대 풀을 사용하도록 수정했다.
- 소수점 정답과 해설의 반올림 표현을 통일했다.
- 7개 은행을 과목별 JSON으로 분리해 화면이 불필요한 다른 과목의 문항을 함께 로드하지 않게 했다.
- 하위 폴더의 문항 파일도 공통 Python 품질 게이트가 재귀 탐색하도록 검사 공백을 막았다.

## 7. 출시 판정과 남은 한계

현재 엔진은 공개된 평가틀과 앱의 출제 계약을 재현하고, 수량·무결성·회차 조립을 자동화하는 출시 가능 상태다. 다만 다음은 자동 검증으로 ‘완벽’을 선언할 수 없는 부분이다.

- 실제 학생 표본의 정답률·변별도·문항별 소요시간은 비공개 시험 운영 데이터 없이 확정할 수 없다.
- 기업·기관별 실제 시험 구성은 채용공고의 변경에 따라 계속 갱신해야 한다.
- 직무적응·인성검사 결과는 표준화된 선발검사 대체재가 아니다.
- 출시 후 첫 응시 데이터를 모으면 영역별 정답률과 응답시간을 기준으로 너무 쉽거나 어려운 문항을 재배치하는 후속 보정이 필요하다.

따라서 출시 표현은 `공식 평가틀·개편 능력표준에 맞춘 독립 실전 연습 문항`으로 사용한다. `공식 기출문항`, `실제 시험과 동일한 문항`, `합격을 보장하는 문항`으로 표시하지 않는다.
