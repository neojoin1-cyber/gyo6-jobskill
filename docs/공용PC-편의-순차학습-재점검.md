# 공용 PC·편의·순차 학습 재점검

## 결론

- 공용 PC의 필수 경계인 계정별 저장, 서버 동기화, 로그아웃 뒤 현재 계정 사본 제거, 오프라인 복구가 연결되어 있다.
- 학생 홈은 오늘의 목표, 이어하기, 과목별 다음 학습을 한 화면에서 제공한다.
- 교사 홈은 복수 학급 전환, 학급별 다음 수업, 학생 성장 신호, 지도 우선순위, 메시지·첨삭·면접 코칭을 제공한다.
- 자율학습은 단원 선택 뒤 카드 학습, 상황 적용, 3문항 형성평가, 다음 단원, 종합 진단의 한 방향으로 진행한다.
- 실전자기소개서와 면접 답변은 작업 중 분기 메뉴를 줄이고 필요한 도구를 해당 단계 안에 배치했다.

## 화면별 점검

1. 학생 홈: 정상
   - 오늘의 루트, 이어하기, 6개 과목별 목표와 다음 학습이 표시된다.
   - 학생은 과목을 고른 뒤 학습 방식만 선택하고, 단원 안에서는 한 개의 다음 행동을 따른다.

2. 실전자기소개서 첫 화면: 개편 완료
   - 지원서 보관함에서 작성 중인 지원서를 고르거나 새 지원서를 만든다.
   - 작성 화면은 `지원처 → 직무 → 전공 → 경험·근거 → 동기·기여 → 문항 → 완성·첨삭` 순서다.
   - 미래 단계는 잠기고, 완료한 이전 단계만 다시 열 수 있다.
   - 근거은행은 별도 상단 탭이 아니라 `경험 증명` 단계에서 연다.
   - 진행 현황 기능은 `지원서 목록`으로 이동해 작성 중 메뉴 경쟁을 없앴다.

3. 면접 답변 연결실: 개편 완료
   - `1분 자기소개 → 지원동기 → 마지막 한마디 → 연결 점검·교사 첨삭` 순서다.
   - 앞 답변이 권장 최소 분량에 도달해야 다음 답변으로 이동한다.
   - 지원서 선택과 자기소개서 근거 연결은 작성 시작 전에 수행한다.

4. 저장·로그아웃: 개편 완료
   - `저장하고 로그아웃`을 누르면 동기화 대기 건수와 공용 PC 사본 제거 조건을 확인한다.
   - 선택지는 `계속 사용`, `저장 후 로그아웃` 두 개로 제한한다.
   - 인터넷이 없으면 기기 계정 공간에 보관하고 다음 로그인 때 동기화한다고 안내한다.

5. 교사 학급 캠퍼스: 정상
   - 담당 학급을 바꾸면 그 학급의 최근 수업 위치와 다음 수업이 바뀐다.
   - 오늘 참여, 푼 문항, 미해결 오답, 도움 필요 학생을 요약한다.
   - 학생별 메시지, 진단, 약한 영역, 진도, 성취, 인성검사, 자기소개서 첨삭, 면접 코칭으로 연결한다.

## 편의 기능 판단

### 출시 전 필수 기능

- 학생: 이어하기, 과목별 다음 학습, 오답 재도전, 진행 초기화, 기기 동기화, 저장 후 로그아웃.
- 교사: 복수 학급 전환, 학급별 다음 수업, 학생별 진행·오답·진단·성취, 우선 코칭, 메시지, 첨삭, 면접 코칭.
- 공통: 직전 화면 뒤로가기, 자동 저장, 오프라인 안내, 공용 PC 사용자 격리.

### 출시 후 운영 데이터로 판단할 기능

- 학생 주간 학습 시간표와 실제 머문 시간 통계.
- 교사의 학생별 지도 메모, 후속 확인일, 조치 완료 상태.
- 학교관리자의 주간 학급 보고서 PDF·엑셀 내보내기.

위 세 기능은 유용하지만 현재 출시를 막는 기능은 아니다. 단순 화면 수를 늘리지 않고 실제 학교 사용 데이터에서 반복 요구가 확인될 때 추가한다.

## 검증 기준

- 한 학습 장면에 서로 경쟁하는 주요 버튼을 두지 않는다.
- 진단·모의고사는 학습 도중 상단 전환 버튼으로 노출하지 않는다.
- 형성평가는 자율학습과 교실 수업 모두에 적용하고, 종합 진단은 단원 학습 완료 뒤에 둔다.
- 작성 도구는 필요한 단계에서만 열고, 작성 중인 문맥으로 돌아오는 길을 제공한다.
- 브라우저 강제 종료는 맞춤 대화상자를 보장할 수 없으므로 즉시 로컬 저장과 재접속 복구를 기본 안전망으로 삼는다.
