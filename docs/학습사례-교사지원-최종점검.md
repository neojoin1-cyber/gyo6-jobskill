# 학습 사례·교사 지원 최종 점검

- 점검일: 2026-08-27
- 범위: 교육부 직업공통, NCS 직업기초, 채용필기 심화, 면접, 자기소개서, 인성검사 자율학습 전체
- 기준: 학생이 먼저 볼 구체 상황·문항·해설, 교사의 현재 페이지 전용 설명·사례·오답·발문, 자료 성격의 정확한 표시

## 결론

교사 지원 자료 기능은 학습 흐름 개편 과정에서 삭제되지 않았다. 현재 학습 카드의 지문·문항·해설을 받아 추가 설명, 좋은 사례, 잘못된 사례, 실수 포인트, 발문, 확인 기준을 만드는 연결도 유지되어 있었다.

다만 점검 전에는 현재 카드 자료가 약할 때 과목 공통 조언으로 대체되어도 이를 자동으로 발견하지 못했고, 학생 화면에서 연습 사례와 공식 공개 기출의 차이가 명시되지 않았다. 면접형 카드에서는 먼저 답해야 할 질문이 핵심 공개 전까지 숨겨질 수 있는 순서 결함도 확인했다.

이번 개편으로 모든 핵심 카드에 자료 성격을 표시하고, 면접 질문은 먼저 보여 준 뒤 답변 핵심만 나중에 공개하도록 수정했다. 교사 추가 자료에도 학생과 같은 자료 성격과 현재 지문·연결 문항을 표시한다.

## 출처와 표현 원칙

현재 콘텐츠 중 출처 메타데이터로 원문을 검증할 수 있는 `공식 공개 문항`은 0개다. 따라서 기존 문항을 실제 기출이라고 부르지 않고, 981개 모두를 다음 중 하나로 표시한다.

- 공개 평가틀 연계 연습
- NCS 능력단위 연계 연습
- 채용 필기형 연습 사례
- 공정채용 면접형 사례
- 고졸 공채 문항형 사례
- 인성검사 응답 원리 사례

공식 기출을 추후 넣으려면 문항마다 공식 원문 여부, 출처명, 원문 URL을 등록해야 한다. 이 메타데이터가 없으면 자동 감사에서 공식 기출 표시를 허용하지 않는다.

## 수정 사항

1. 학생 사례 상단에 자료 성격, 기준 연결 설명, 기출 오인 방지 문구를 추가했다.
2. 교사 지원의 `추가 자료`에 같은 자료 성격과 현재 카드의 지문·문항을 표시했다.
3. 면접 카드는 질문을 먼저 제시하고 20초 동안 답하게 한 뒤 모범 답변 핵심·확인 기준을 공개하도록 순서를 바로잡았다.
4. 면접 원자료의 인용문 질문을 학습 질문으로 읽고, `셀프 체크 기준:` 같은 불완전한 라벨은 질문 후보에서 제외했다.
5. 단원 개요·용어·마무리처럼 별도 문항이 없는 화면도 현재 카드 핵심 또는 과목별 적용 활동을 교사 사례로 제공하도록 보강했다.
6. 6과목 전체를 검사하는 `verify:context-materials`를 출시 전 `prebuild`에 포함했다.

## 검증

- `npm run verify:context-materials`: 172단원, 핵심 981개, 교사 자료 2,214페이지 통과
- `npm run verify:learning-experience`: 172단원, 실제 문항 연결 981개, 실제 오답 369개, 상황 삽화 981개 통과
- `npm run verify:learning-render`: 원문항 1,976개, 형성평가 172개, 듣기 8개, 표·그래프 7개, 먼저 판단·정답 숨김 통과
- `npm run verify:teacher-release`: 6개 학습관, 수업 대화 90개, 면접 질문 168개, 인성 문항 1,030개 통과
- `npm run verify:first-class`: 6과목 첫 수업 45분·6단계와 3문항 형성평가 통과
