# 아침 훈화 자료 규격 (학생 출석 · 교사 조회 공용)

하나의 원고가 두 곳에 쓰인다. 학생은 출석할 때 짧게 읽고 연계 문항 1개를 풀고,
교사는 같은 원고를 조회 자료로 띄운다. 그래서 **학생용 본문과 교사용 진행안을
한 레코드에 함께** 담는다. 따로 만들면 두 배로 들고 내용도 어긋난다.

## 대상

특성화고·마이스터고 2~3학년. 곧 현장실습·취업을 앞두고 있다.
- 훈계조·설교조 금지. "~해야 한다"보다 **장면과 사실**로 말한다.
- 성공담 미화 금지. 실패·서투름을 다루되 비참하게 만들지 않는다.
- 특정 종교·정당·기업 홍보 금지. 실존 인물 일화는 검증 가능한 것만.
- 학력·집안·외모로 사람을 가르는 표현 금지.

## JSON 스키마 (data/morning-talks.json 의 한 항목)

```json
{
  "id": "MT-001",
  "theme": "시간 약속",
  "title": "3분 먼저 도착한 사람",
  "body": "4~6문장. 학생에게 말하듯 평이하게. 한 장면으로 시작해 한 가지만 남긴다.",
  "oneLine": "20자 안팎. 카드에 크게 뜨는 오늘의 한 줄.",
  "area": "직업윤리",
  "question": {
    "stem": "훈화 내용을 실제 상황에 옮겨 보는 문항. 훈화를 읽어야 풀린다.",
    "choices": ["...", "...", "...", "..."],
    "answer": "B",
    "explanation": "왜 그 답인지 2~3문장. 나머지가 왜 아닌지도 짚는다."
  },
  "teacherNote": {
    "openQuestions": ["교실에서 던질 발문 2개"],
    "tip": "진행 팁 1~2문장. 시간 배분이나 주의할 반응."
  }
}
```

## 지켜야 할 것

- `area` 는 NCS 26v1 7영역 중 하나만: 의사소통능력 · 수리능력 · 문제해결능력 ·
  자기관리능력 · 대인관계능력 · 디지털능력 · 직업윤리
- `body` 는 공백 포함 **250~400자**. 아침 조회 2분 분량이다.
- `question.choices` 는 4개. 정답은 A~D 중 하나이며 **한 개만** 참이어야 한다.
- 보기 본문에 `A.` 같은 표기를 넣지 않는다(앱이 번호를 따로 붙인다).
- 문항은 훈화를 읽지 않으면 못 풀어야 한다. 상식으로 풀리면 출석 의례가 헛돈다.
- `oneLine` 은 본문의 요약이지 새 주장이 아니다.
