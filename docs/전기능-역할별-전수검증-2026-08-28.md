# 전 기능 역할별 전수 검증 보고서

- 검증일: 2026-08-28
- 대상: 학생 앱, 교사 앱, 공개 체험, 운영 Supabase 읽기 경로, Android 내부 테스트 빌드
- 방법: 실제 브라우저 조작, 역할별 운영 RPC 자동 검증, 데이터 전수 감사, 전체 출시 게이트, Android 종료·복구 및 PC·휴대폰 동기화 검증

## 결론

학생의 6개 학습관과 교사의 다중 학급·수업·분석·첨삭 흐름을 처음부터 끝까지 점검했다. 대량 추가 데이터는 학과·기업·평가·교사지원 경계를 포함해 전수 또는 조합 전수 방식으로 검사했다. 검증 중 발견한 실제 결함 5건을 수정하고 회귀 방지 검사를 추가했다.

## 발견·수정

1. 기업별 평가 600문항의 정답 위치가 첫 번째 선택지에 치우친 문제를 수정했다. 현재 분포는 A 150, B 151, C 151, D 148이다.
2. 면접 모의고사가 옛 영역 분류를 사용해 `총 0문항`으로 표시되던 문제를 공통 범위 엔진에 연결했다. 현재 10개 영역, 총 880문항이다.
3. 교사 공개 체험의 진단·약점·진도·인성 화면이 체험 학급 ID를 운영 DB UUID로 조회해 오류 문구를 노출하던 문제를 수정했다.
4. 교사 공개 체험의 3개 학급별 분석·형성평가·면접 코칭 데이터가 한 학급에만 머물던 문제를 3개 학급별 독립 데이터로 보완했다.
5. 교사 작업대 안의 분석 화면에 동작하지 않는 뒤로가기 버튼이 노출되고 Android 뒤로가기를 빈 처리기가 가로채던 문제를 제거했다.

## 학생 앱 실제 조작

1. 홈에서 6개 학습관, 오늘의 루트, 과목별 목표와 다음 학습을 확인했다.
2. 6개 학습관에서 자율학습·진단평가·실전 기능으로 각각 진입했다.
3. 자율학습에서 추천 영역 → 추천 단원 → 상황 파악 → 먼저 판단 → 근거 공개 → 조건 변경 → 다음 장면 순서를 확인했다.
4. 단원 말미의 3문항 형성평가와 변형 1문항, 해설, 보완 경로를 확인했다.
5. 면접 학습의 6개 기초 과정·48단원과 순차 진행 잠금을 확인했다.
6. 면접 진단에서 전체 880문항, 영역 10개, 소단원 137개를 확인하고 5문항 응시·결과·보완 순서까지 완료했다.
7. 면접 모의고사에서 범위 선택, 5문항 시작, 타이머, 문항 도구, 이전·다음 이동을 확인했다.
8. 실전면접의 9단계 리허설과 1분 자기소개·지원동기·마지막 한마디의 순차 작성 연결을 확인했다.
9. 자기소개서관에서 다중 지원서, 근거은행, 7단계 순차 작성, 자동 저장, 교사 첨삭 요청 경로를 확인했다.
10. 기업 엔진에서 금융 30곳·공공 40곳·대기업 50곳의 검색·필터·기업 상세·맞춤 점수·5단계 학습·공식 출처를 확인했다.
11. 소식, 선생님 답장, 성장 기록, 공용 PC 저장 후 종료, 사용자별 기기 저장 격리를 정적·운영 게이트로 확인했다.

## 교사 앱 실제 조작

1. 3개 담당 학급을 바꾸며 학급명·참여·오답·학생·다음 수업이 함께 바뀌는지 확인했다.
2. 학생 성장, 진단 현황, 약한 영역, 학습 진도, 성취 결과, 인성검사 메뉴를 모두 열었다.
3. 다음 수업을 눌러 해당 학급의 직전 위치에서 교실 수업이 시작되는지 확인했다.
4. 교사 지원을 열어 첫 수업 45분·6단계 흐름, 교사 멘트, 제시 자료, 학생 활동, 형성평가를 확인했다.
5. 수업 집중 화면에서도 교사 지원이 유지되고 공개 가능한 탭만 남는지 확인했다.
6. 화면 뒤로가기가 현재 장면 → 단원 → 영역 → 교사 작업대 순으로 직전 화면에 복귀하는지 확인했다.
7. 자기소개서·면접답변 첨삭실에서 지원 건별 문서, 빠른 평가, 문단 메모, 전체 조언, 수정 요청을 확인했다.
8. 메시지의 학급·개인 선택, 빠른 시작 문구, 제목·내용 입력, 학생 답장함을 확인했다.
9. 미션 만들기와 면접 9단계 관찰표의 메뉴 연결·데이터 계약을 출시 게이트로 확인했다.
10. 운영 공개 체험 계정으로 교사 진단·진도·약점·인성·학생·순위·수업·수신함 RPC를 확인했다.

## 데이터·엔진 전수 결과

- 기업 120곳: 금융 30, 공공 40, 대기업 50
- 기업 평가문항 600개: 기업당 5개, 문항·선택지·정답·중복 전수 통과
- 학생 프로필 × 기업 맞춤 조합 1,200건: 점수·추천 직무·강점·보완점·초안 연결 전수 통과
- HIFIVE 기반 573개교, 우선 학과 300개, 세부 전공 296개
- 개인화 예시: 자기소개서 129,600개, 면접 12,960개
- 전체 학습단원 172개, 핵심 카드 981개, 학생 사례 981개, 교사 지원자료 2,214페이지
- 평가 중요도: 최신 274, 빈출 830, 기출 1,103, 중요 482
- 전체 품질 게이트: 40개 파일, 5,765문항, 차단 위반 0건
- 공식 문항 권리: 미승인 원문 탑재 0건
