# 학생 자율학습 UI·UX 및 근거 연결 최종 점검

점검일: 2026-08-28  
대상: 교육부 직업공통능력, NCS 직업기초능력, 채용필기 심화, 면접, 자기소개서, 인성검사 자율학습

## 결론

- 과목 입구의 첫 행동을 `자율학습` 하나로 고정하고 진단·모의·실전은 보조 메뉴로 접었다.
- 영역과 단원마다 진행 기록을 읽어 `추천 시작` 또는 `이어서 학습`을 가장 먼저 제시한다.
- 자유 선택 목록과 전체 문제 기능은 없애지 않고 `다른 영역·단원 보기`, `복습용 전체 문제 보기`로 내렸다.
- 단원 시작 화면은 콘텐츠 개수 대신 `상황 파악 → 근거 연결 → 새 상황 적용`과 구체적인 완료 목표를 보여 준다.
- 정답 공개 뒤에는 번들된 지문·해설·정답만으로 `자료의 단서 → 판단 기준 → 결론`을 표시한다. 외부 AI API를 호출하지 않는다.

## 콘텐츠 연결 검사

- 172개 학습단원
- 1,563개 자율학습 원문항의 상황·사례·문장·자료·빈칸 연결 검사
- 원인·결과 직접 문항 162개 해설 근거 검사
- 981개 핵심 카드
- 492개 선택·빈칸형 카드의 3단 근거 연결 렌더링 검사
- 172개 단원의 3문항 형성평가와 새 상황 변형 문항 검사

검사 규칙은 `scripts/audit-learning-experience.mjs`와 `scripts/audit-learning-render.mjs`에 포함했다. 이후 콘텐츠를 추가해도 상황이나 빈칸의 위치가 없거나 원인·결과 해설이 빠지면 빌드가 실패한다.

## 실제 흐름 점검

1. 과목 선택
2. 추천 자율학습 시작
3. 추천 영역 또는 이어서 할 영역 선택
4. 추천 단원 또는 이어서 할 단원 선택
5. 단원 목표와 3단계 학습 순서 확인
6. 먼저 판단하고 선택
7. 정답·해설과 3단 근거 연결 확인
8. 조건 변화 심화 활동
9. 직접 행동 정리
10. 3문항 형성평가와 학습 마무리

각 화면으로 이동할 때 학습 본문이 항상 맨 위에서 시작하도록 스크롤 복원도 확인했다.

## UI 판단

- 기존 캠퍼스 이미지와 색상 체계는 브랜드 자산으로 유지했다.
- 같은 기능을 반복 설명하던 과목 기능 요약은 숨기고 실제 첫 행동을 상단에 배치했다.
- 휴대폰 프레임과 실제 모바일에서는 근거 연결을 세로로 표시하고, 교사 와이드 화면에서만 3열을 허용한다.
- 작은 화면에서도 버튼 제목, 진행률, 시작 행동이 서로 겹치지 않도록 고정된 그리드와 줄바꿈을 사용한다.
- 학습 내용은 읽기만 하는 페이지가 아니라 판단, 선택, 근거 확인, 조건 변화, 직접 정리, 형성평가의 순서로 진행된다.
