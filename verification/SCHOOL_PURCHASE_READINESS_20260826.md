# 학교 구매·수업 운영 출시 검증 보고서

- 검증일: 2026-08-26
- 대상: 학생 앱, 교사 웹, 학교관리자 웹, 공개 웹 체험, Android 출시 번들
- 결론: 학교 시연과 도입 검토에 사용할 수 있는 출시 후보 상태

## 교사 수업 지원

- 담당 학급 3개 전환과 선택 학급 유지 확인
- 학급별 6개 학습관의 `수업 전 / 진행 중 / 완료` 상태와 다음 차시 표시
- 최근 진행 중인 단원을 상단 `다음 수업`에서 한 번에 재개
- 선택 학급과 정확한 과목·영역·단원이 교실 화면까지 전달됨
- 학생 앱과 같은 학습 화면에서 교사 지원, 집중 화면, 학생 기기 연결 사용
- 수업 종료 후 교사 캠퍼스로 복귀하고 선택 학급이 유지됨

운영 DB에는 `class_lesson_progress`를 적용했다. 수업 중 전달되는 학습 단계가 마지막 `end` 카드에 도달하면 단원 완료로 기록하며, 그 전에는 진행 중으로 남긴다. 유료 AI API는 사용하지 않는다.

## 학생 자율학습

- 6개 학습관 모두 과목 고유 목표, 현재 진도, 다음 학습을 첫 화면에서 제공
- 과목 행을 한 번 누르면 첫 단원 또는 마지막 학습 단원으로 이동
- 영역 선택 화면이 실제 학습 이력으로 잘못 저장되지 않도록 차단
- 172개 자율학습 단원에 먼저 판단, 능동 확인, 3문항 형성평가, 해설, 마무리 카드 확인
- 첫 수업 5과목은 각 45분·6단계이며 형성평가 3문항 중 1문항은 변형 적용 문항
- 듣기 자료 51개와 실제 듣기 학습 8개 렌더링 확인

## 운영 유의사항

- 공개 체험 계정은 의도적으로 읽기 전용이므로 체험 중 생성한 진도는 저장하지 않는다.
- 정식 학교·교사·학생 계정의 수업과 학습 기록만 운영 DB에 저장한다.
- 정식 계정 쓰기 전체 흐름 자동 검증은 별도 데모 비밀번호가 제공될 때 실행하며, 공개 체험 역할·메뉴·보안 검증은 완료했다.
