# 코워크 담당 — 2가지

검증 실행은 전부 클로드 코드가 한다. 코워크는 클로드 코드가 구조적으로 할 수 없는 것만 맡는다.

## 1. 문항 독립 채점 (CNT 정답 판정)

클로드 코드는 앱의 정답을 알고 있으므로 독립 판정자가 될 수 없다.

- 입력: `handoff/CNT_blind_questions.json` — 정답·해설이 제거된 문항 세트
- 작업: 지문과 보기만 보고 독립 정답과 근거를 산출한다. 앱 값을 절대 먼저 보지 않는다.
- 출력: `handoff/CNT_independent_answers.json`
  `{ questionId, independentAnswer, rationale, confidence, flags[] }`
- flags 예시: 지문 없이 답할 수 있음 / 복수 정답 / 정답 없음 / 보기 포함관계 /
  상식 논쟁 / 질문과 해설의 인명·직무·수치·날짜 불일치
- 불일치는 클로드 코드가 앱 값과 대조해 원장에 P1로 등록한다.
- 층화: 교육부 직업공통능력 5개 영역 각 30문항 + 고위험 전수 / NCS 26v1 하위능력별 10문항 이상 /
  채용필기 지원처 유형별 30문항 / 식음료서비스 단원별 10문항 / 자기소개서 30유형 전부 /
  면접 기초 168 + 심화 표본

## 2. 최종 판정서

- 입력: `LEDGER.md` 전체와 `evidence/`
- 출력: `verification/adversarial-4.8.13/VERDICT.md`
- 내용: GO / CONDITIONAL GO / NO-GO, 근거, 미충족 조건, 부록 C 최종 승인 체크리스트,
  그리고 검증하지 못한 항목(실기기 미검증 등)을 잔여 위험으로 명시.
- P2 위험 승인은 소유자 서명란을 비워 둔다. 대신 서명하지 않는다.

## 하지 않는 것

시나리오 실행, 원인 규명, 수정, 재시험. 전부 클로드 코드 몫이다.
