# 5과목 첫 수업 흐름 재검토 및 최종안

- 작성일: 2026-08-26
- 범위: 직업공통능력 인증평가, NCS 직업기초능력, 채용필기 심화, 면접 스킬, 인성검사
- 수업 시간: 과목별 45분
- 공통 원칙: `상황·자료 제시 → 개인 첫 판단 → 근거 공개·비교 → 조건 변경·재판단 → 실전 행동 확정 → 형성평가 3문항 → 정리`

## 1. 재검토 결론

기존 흐름의 큰 방향은 맞지만, 학생이 개념 설명을 먼저 읽고 답을 따라가는 수동 학습이 되지 않도록 화면 위치와 교사 행동을 다음 순서로 고정한다.

1. 도입 화면은 과목 소개가 아니라 오늘 할 수 있어야 할 행동을 알리는 데만 사용한다.
2. 모든 핵심 카드에서 실제 상황·제시문·음성·표를 먼저 보여 준다. 자료가 없으면 `상황`이라고 부르지 않는다.
3. 해설과 모범 답은 학생의 첫 판단 뒤에만 연다.
4. 근거 공개 뒤에는 `판단 유지·판단 수정·정보 더 필요` 중 하나를 다시 선택하고 이유를 말하게 한다.
5. 마지막 핵심 뒤에 `내 실전 행동 확정`을 두어 다음 문제에서 쓸 기준을 학생 문장으로 남긴다.
6. 형성평가는 반드시 마지막 행동 확정 뒤에 둔다. 1·2번은 오늘 배운 기준, 3번은 표현과 조건을 바꾼 변형 문항이다.
7. 정리 화면은 점수만 보여 주지 않고 `오늘 꼭 기억할 3가지`, 틀린 이유, 다음에 먼저 볼 조건을 함께 제시한다.

이 흐름은 교실 수업과 자율학습이 공유한다. 교실에서는 교사가 질문·짝 토의·발표를 진행하고, 자율학습에서는 화면이 같은 질문과 재판단 단계를 안내한다. 진단평가와 모의고사는 실력을 측정하는 화면이므로 이 형성평가를 덧붙이지 않는다.

## 2. 직업공통능력 인증평가 첫 수업

**경로:** `직업공통능력 인증평가관 → 자율학습 → 의사소통 국어 → 의사소통 국어 핵심 점검`

**목표:** 긴급성·처리 권한·핵심 조치를 구분하여 첫 행동을 근거와 함께 결정한다.

| 시간 | 수업 위치·버튼 | 교사가 말할 내용 | 제시 자료 | 학생 활동 |
|---|---|---|---|---|
| 0~3분 | 과목 홈에서 `자율학습` | “정답 번호보다 현장에서 가장 먼저 할 행동을 근거와 함께 찾겠습니다.” | 교육부·대한상공회의소 인증평가 안내 | NCS 필기와 이 평가의 차이를 한 문장으로 말함 |
| 3~8분 | `의사소통 국어 핵심 점검 → 학습 시작 → 먼저 판단` | “고객 불만, 당일 18시, 신입사원 중 첫 행동을 바꾸는 조건은 무엇일까요?” | 긴급 고객 불만 업무 지시서 | 개별 선택 후 화면 근거 한 곳을 표시 |
| 8~15분 | 첫 핵심에서 `핵심 보기 → 판단 유지·수정·정보 더 필요` | “고객에게 바로 전화하는 것과 상급자에게 보고하는 것의 차이는 친절이 아니라 무엇일까요?” | 처리기한·담당 권한·보고 절차 | 짝과 근거를 비교하고 재선택 |
| 15~27분 | 다음 핵심에서 `다음 → 근거 공개` | “공지의 사유와 직원이 실제로 해야 할 조치를 구분해 봅시다.” | 정전 업무 조정 공지 | 사유·핵심 조치·문의처를 구분 |
| 27~36분 | `실전 행동 카드 → 내 실전 행동 확정` | “마감이 내일로 바뀌고 담당 권한이 생기면 첫 행동도 같을까요?” | 조건 변경 질문·말하기 틀 | 판단이 바뀌는 경계를 한 문장으로 말함 |
| 36~45분 | `형성평가 시작 → 정답·해설 확인 → 학습 정리` | “1·2번은 오늘 기준, 3번은 처음 보는 상황에 같은 기준을 적용합니다.” | 3문항 형성평가 | 개별 응답, 오답 이유, 다음 확인 조건 기록 |

**형성평가 핵심:** ① 신입사원의 첫 보고 ② 정전 공지의 실제 조치 ③ 처리 권한이 이미 있는 변형 상황. 정답 해설은 긴급성만이 아니라 권한·사실·마감을 함께 보도록 설명한다.

## 3. NCS 직업기초능력 첫 수업

**화면 경로:** `NCS직업공통능력관 → 자율학습 → 의사소통능력 → 문서소통능력`
**공식 학습 체계:** 고용노동부·한국산업인력공단 `NCS 직업기초능력 26v1`

**목표:** 문서의 요구사항·사실과 의견·출처를 구분하고 목적에 맞는 행동을 결정한다.

| 시간 | 수업 위치·버튼 | 교사가 말할 내용 | 제시 자료 | 학생 활동 |
|---|---|---|---|---|
| 0~4분 | 과목 홈에서 `자율학습` | “문서를 처음부터 외우듯 읽지 말고 발문에서 구할 것을 먼저 정합니다.” | NCS 의사소통능력 구조 | `발문 → 정보 → 판단 → 검산` 순서를 확인 |
| 4~10분 | `문서소통능력 → 학습 시작 → 먼저 판단` | “배경 설명을 걷어내면 상대가 실제로 요구한 행동은 무엇인가요?” | 개정 단가표 서명·회신 문서 | 요구 표현과 금요일 마감을 표시 |
| 10~18분 | 다음 핵심에서 `핵심 보기` | “집계된 수치와 ‘그런 것으로 보인다’는 표현은 어떻게 다릅니까?” | 사실 문장·의견 문장 | 두 칸으로 분류하고 근거 표현 발표 |
| 18~28분 | `문서 신뢰성 카드 → 판단 선택 → 근거 공개` | “표와 숫자가 많다는 이유만으로 믿어도 될까요?” | 작성자·작성일·원출처가 빠진 통계 | 세 출처 확인 항목과 확인 순서를 말함 |
| 28~36분 | `논리적 흐름 카드 → 내 실전 행동 확정` | “처음 두 문장만 읽어도 목적과 결론이 보이나요?” | 결론 우선 문서·나열 문서 | 목적·결론을 앞에 두고 근거를 재배치 |
| 36~45분 | `형성평가 시작 → 정답·해설 확인 → 학습 정리` | “3번은 요청·마감·출처를 동시에 확인해야 합니다.” | 3문항 형성평가 | 각 답의 근거 표현을 자료에서 직접 찾음 |

**형성평가 핵심:** ① 회신 요구와 마감 ② 사실·의견 구분 ③ 발신자와 출처가 없는 새 안전 절차 문서. 해설은 형식의 그럴듯함보다 공식 출처를 먼저 검증하게 한다.

## 4. 채용필기 심화 첫 수업

**경로:** `채용필기 심화관 → 자율학습 → 공공기관형 → 자원배분·관리 → 자원의 종류와 특성 이해`

**목표:** 인적·물적·재무·시간 자원을 구분하고 확정·미확정 조건을 가려 실행 가능한 배분을 판단한다.

| 시간 | 수업 위치·버튼 | 교사가 말할 내용 | 제시 자료 | 학생 활동 |
|---|---|---|---|---|
| 0~4분 | 과목 홈에서 `자율학습 → 공공기관형` | “이 과정은 NCS 공통 위에 지원처별 추가 영역을 얹는 심화입니다.” | 공공기관형 범위·공고 확인 안내 | 공통 NCS와 채용 심화를 구분 |
| 4~11분 | `자원배분·관리 → 자원의 종류와 특성 이해 → 학습 시작` | “사람·돈·시스템·시간에 해당하는 정보를 각각 찾아봅시다.” | 인력 5명·예산 1,200만원·시스템 도입안 | 네 자원 유형을 서로 다른 표시로 구분 |
| 11~19분 | 첫 핵심에서 `핵심 보기 → 판단 재선택` | “회의에서 언급되었다고 모두 확정된 자원일까요?” | 800만원 확정·400만원 선택·충원 승인 대기 | 확정·선택 필요·승인 대기로 분류 |
| 19~28분 | 다음 핵심에서 `근거 공개` | “인원과 예산 합계가 원자료와 맞고 빠진 자원이 없는지 봅시다.” | 공사 인력·예산·임시 사무실 배분표 | 합계 계산과 결정 표현 표시 |
| 28~36분 | 조건 변경에서 `판단 유지·수정·정보 더 필요 → 내 실전 행동 확정` | “승인 전 충원을 확정처럼 넣으면 어떤 계획 오류가 생길까요?” | 승인 전 충원을 넣은 실행안 | 현재 실행안과 승인 후 수정안을 분리 |
| 36~45분 | `형성평가 시작 → 정답·해설 확인 → 학습 정리` | “3번은 새 예산안에서 확정과 승인 대기를 동시에 구분합니다.” | 3문항 형성평가 | `자원 종류 → 확정 여부 → 합계`로 설명 |

**형성평가 핵심:** ① 현재 확정된 배분 ② 네 자원 유형 ③ 장비 예산만 확정된 변형안. 해설은 승인되지 않은 자원을 임의로 실행안에 포함하지 않게 한다.

## 5. 면접 스킬 첫 수업

**경로:** `면접 스킬관 → 자율학습 → 면접 이해와 전형 준비 → 면접시험 전체 개요 및 진단평가`

**목표:** 평가 관점을 이해하고 STAR·블라인드 원칙으로 실제 경험 답변을 구성한다.

| 시간 | 수업 위치·버튼 | 교사가 말할 내용 | 제시 자료 | 학생 활동 |
|---|---|---|---|---|
| 0~4분 | 과목 홈에서 `자율학습` | “모범답을 외우지 않고 면접관이 확인할 것을 내 경험으로 답합니다.” | 기관·직무별 평가항목 안내 | 고정 합격선 시험이 아님을 확인 |
| 4~11분 | `면접시험 전체 개요 → 기준 익히기 시작` | “서류의 사실 말고 면접에서 새로 확인하려는 것은 무엇일까요?” | 인성·직무역량·소통·성장가능성 | 자신 있는 관점과 증명 경험을 연결 |
| 11~20분 | STAR 카드에서 `20초 먼저 답하기 → 핵심 보기` | “상황이 길어지면 내가 한 행동이 사라집니다. 무엇을 가장 구체적으로 말할까요?” | STAR 구조 | 30초 답변 후 Action에 표시 |
| 20~28분 | 블라인드 카드에서 `판단 선택 → 선택 후 심화` | “학교명을 빼도 역량 근거가 남도록 어떻게 바꿀까요?” | 학교·지역·가족 배경이 든 감점 답변 | 금지 정보 삭제, 역할·행동·결과 유지 |
| 28~36분 | `답변 고쳐 고르기 → 수정안 선택 → 확인` | “좋아 보이는 문장이 아니라 질문과 경험 근거가 연결된 수정을 고르세요.” | 답변 약점·네 수정안 | 선택 근거와 다른 수정안의 문제 설명 |
| 36~45분 | `형성평가 시작 → 정답·해설 확인 → 학습 정리` | “3번은 블라인드와 STAR를 함께 적용하는 새 답변입니다.” | 3문항 형성평가 | 응답 후 자기 경험 키워드 3개 기록 |

**형성평가 핵심:** ① 확인하기 어려운 추상 답변 ② STAR의 Action ③ 블라인드와 행동·수치 결과를 모두 지킨 변형 답변. 해설은 학교·가족 정보 없이도 경험 근거가 남아야 함을 설명한다.

## 6. 인성검사 첫 수업

**경로:** `인성검사훈련관 → 자율학습 → 검사 이해 → 인성검사의 목적`

**목표:** 정답 시험과 응답 경향 검사를 구분하고 평소 행동 기준·일관성·과장 위험을 이해한다.

| 시간 | 수업 위치·버튼 | 교사가 말할 내용 | 제시 자료 | 학생 활동 |
|---|---|---|---|---|
| 0~4분 | 과목 홈에서 `자율학습` | “회사가 좋아할 답이 아니라 내 평소 행동을 왜곡 없이 답하는 원칙을 익힙니다.” | 정답 없는 응답 경향 검사 안내 | 적성검사와 인성검사의 차이를 말함 |
| 4~12분 | `인성검사의 목적 → 학습 시작 → 내 기준 선택` | “능력 문제와 평소 행동 경향을 묻는 검사는 어떻게 다를까요?” | 적성·인성·인적성 비교 | 세 검사 목적을 분류 |
| 12~20분 | 결과 카드에서 `선택 → 내 기준 확인하기` | “성실성 수치 하나가 낮으면 사람 전체가 부적합한 걸까요?” | 응답 경향·신뢰도·면접 참고자료 | 결과를 판정이 아닌 참고자료로 다시 표현 |
| 20~29분 | 함정 카드에서 `선택 후 심화` | “모든 장점 문항에 최고점을 주면 왜 실제 모습이 흐려질까요?” | 과장 응답과 실제 행동 기준 | 최근 행동 장면으로 선택 이유를 설명 |
| 29~36분 | 유사 문항 카드에서 `판단 유지·수정·정보 더 필요 → 내 실전 행동 확정` | “표현 방향이 반대여도 같은 행동 기준을 유지했는지 봅시다.” | 긍정문·부정문 유사 문항 | 부정어 표시 후 두 응답 기준 비교 |
| 36~45분 | `형성평가 시작 → 정답·해설 확인 → 학습 정리` | “3번은 좋은 성향을 고르는 문제가 아니라 바른 응답 절차를 묻습니다.” | 3문항 형성평가 | 원칙 하나와 피할 습관 하나 기록 |

**형성평가 핵심:** ① 검사 준비 원칙 ② 결과 해석 ③ 반대 방향의 유사 문항 변형. 여기서 정답은 사람의 성향이 아니라 문항을 읽고 응답하는 절차에만 존재한다.

## 7. 화면 배치 최종 규칙

1. 상단: 현재 단원명과 전체 진행률.
2. 왼쪽 또는 첫 영역: 실제 상황·제시문·음성·표. 오독 사례는 `제시문`과 `잘못 읽은 뜻`을 분리 표시.
3. 오른쪽 또는 다음 영역: 학생의 첫 선택. 답·해설은 선택 전 숨김.
4. 선택 직후: 정답 근거, 처음 판단과의 차이, 조건 변경 질문.
5. 단원 후반: `내 실전 행동 확정`.
6. 끝에서 두 번째: 3문항 형성평가. 세 문항의 해설 확인 전에는 다음으로 이동할 수 없음.
7. 마지막: 형성평가 점수, 오늘 꼭 기억할 3가지, 다음 적용 행동.

|---|---:|---:|---:|---:|

앱 구현에서는 `StudySummary`를 쓰는 모든 자율학습 단원에 이 구조가 자동 적용된다. 첫 수업 다섯 개는 별도 검토한 문항을 사용하고, 다른 단원은 해당 단원의 실제 학습 문항 두 개와 새 상황 변형 문항 한 개를 사용한다. 외부 생성형 AI API는 호출하지 않는다.
